🎮 JavaScriptでつくるアクションゲーム「Super JS Bros」

〜 ブラウザだけで動くマリオ風ゲームの自作に挑戦する探求活動 〜

探求テーマ：ゲームプログラミング 使用言語：HTML / CSS / JavaScript 進捗状況：探求中（初期〜中期段階）

1探求の動機・目的

幼い頃から遊んでいたアクションゲームに憧れ、「自分でも同じような仕組みを作れるのか」を確かめたいと考え、 プログラミング未経験からJavaScriptでの2Dアクションゲーム制作に挑戦することにした。

2制作物の概要

ブラウザの<canvas>だけで動く横スクロール型アクションゲーム。プレイヤーを操作し、 コインやアイテムを集めながらゴールを目指す、いわゆる「マリオ風」ゲーム。

3使用技術

  • HTML5 Canvas によるグラフィック描画
  • JavaScript によるゲームループ・当たり判定・敵AI
  • 外部ライブラリ不使用（すべて自作コード）

4実装できた機能

  • 左右移動・ジャンプ操作、複数種類の敵とその当たり判定
  • コイン・パワーアップ（スピード／巨大化／ファイア／無敵）アイテム
  • 全5ステージ構成、ステージ3以降はボスキャラクターが登場
  • スコア・残り機数・レベル表示のUI実装

5現在の進捗

全体の完成度（現時点・探求中のため低め）

  • 基本的な移動・ジャンプ・当たり判定 → 完了
  • 5ステージ分のマップと敵配置 → 完了
  • サウンド・エフェクトの追加 → 未着手
  • 難易度調整・バランス確認 → 進行中

6苦労した点・工夫

坂道や階段状の地形で敵やアイテムが埋まってしまう不具合が発生。地形データから 実際に足場のある座標を計算し直す仕組みを導入して解決した。

7今後の展望

  • ① 効果音・BGMの追加でゲーム体験を向上
  • ② スマートフォン操作（タッチ操作）への対応
  • ③ ステージ数を増やし、新しい敵・ギミックを追加
  • ④ 友人にプレイしてもらいフィードバックを反映

8まとめ

プログラミング未経験からのスタートだったが、JavaScriptのみで基本的なアクションゲームの仕組み （操作・当たり判定・敵AI・ステージ進行）を実装できた。現段階では探求の途中であり完成度は高くないが、 今後は演出面・操作性・コンテンツ量を強化し、より遊びごたえのあるゲームへ発展させていきたい。
